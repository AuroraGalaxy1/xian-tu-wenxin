# 《全职法师：天选之外》——游戏世界观设定集（最终版）

## 一、总览

### 1.1 游戏基本信息

| 项目 | 内容 |
| --- | --- |
| **游戏名称** | 《全职法师：天选之外》 |
| **类型** | 文字冒险游戏（基于选择驱动的叙事） |
| **世界观基底** | 小说《全职法师》原著 |
| **时间节点** | 圣城之战后 **第五年** |
| **故事起点** | 华夏 · **魔都** · 明珠学府预科部 / 某公立魔法高中 |
| **玩家身份** | 16岁新晋法师，**博城灾难**的幸存遗孤，在魔都长大 |
| **核心主题** | “莫凡之外，还有无数普通人在守护这个世界” |

### 1.2 世界观版本说明

本设定集已根据原著资料进行**全面修正**：

-   ❌ 删除了不存在的“博城重建为英雄之城”设定
    
-   ❌ 删除了不存在的“博城地底深渊巨蟒封印”设定
    
-   ❌ 删除了已停办的“天澜魔法高中”设定
    
-   ❌ 删除了“博城海妖袭击”等错误事件描述
    
-   ✅ 修正了博城灾难的实际原因（黑教廷血色警戒）
    
-   ✅ 修正了古老王、亡灵帝国等后期设定的状态
    
-   ✅ 确认了圣城变革后的世界格局
    
-   ✅ 确认了各魔法系别的初阶觉醒规则
    

### 1.3 叙事原则

1.  **尊重原著结局** —— 所有核心角色的最终状态以原著为准，不随意改写
    
2.  **不弱化莫凡** —— 莫凡的成就作为世界背景存在，不通过“莫凡不过如此”来抬高玩家
    
3.  **普通人的史诗** —— 玩家是“莫凡之外”的人，走自己的路，不需要超越莫凡才有价值
    
4.  **世界仍有威胁** —— 原著未填的坑（南极帝王、海洋帝王、黑暗王）是游戏的天然素材
## 二、时间线设定

### 2.1 完整时间线（以游戏起始年为基准）

| **约 8-9 年前** | 莫凡考入明珠学府，开启传奇之路。许昭霆等博城幸存者在魔都继续学业 |

### 2.2 博城灾难详情（玩家角色背景）

#### 2.2.1 不可更改的原著事实

1.  黑教廷策划，布局**十余年**
    
2.  提前在博城地底开掘通道，使妖魔直接涌入城区
    
3.  虐杀翼苍狼幼崽，引**翼苍狼**（统领级）袭击博城
    
4.  制造假地圣泉，使妖魔进入**狂暴状态**
    
5.  唐月以**教师身份**潜伏博城调查
    
6.  莫凡、宇昂、唐月等人**介入事件**
    
7.  灾难后**博城被放弃**，不再适合居住
    
8.  莫凡最终获得真正的**地圣泉**
    

#### 2.2.2 游戏中的应用

-   玩家作为幼儿幸存者，对灾难只有**模糊记忆** —— 红色的天空、尖叫声、被陌生人抱上离开的车
    
-   这份模糊记忆是**贯穿全作的情感线索**
    
-   博城灾难的直接始作俑者 —— 黑教廷部分成员 —— 虽已被清洗，但“博城”这个名字依然是玩家的**心结**

## 四、魔法体系设定

### 4.1 四大魔法类别与初阶觉醒规则

| 大类 | 包含系别 | 初阶觉醒规则 |
| --- | --- | --- |
| **元素魔法** | 火、水、风、土、冰、光 | ✅ 常规觉醒，概率均分 |
| **元素魔法 · 雷系** | 雷 | ✅ 概率约 **0.1%**（千分之一） |
| **白魔法** | 治愈、心灵、植物 | ⚠️ 极低概率（约 **2%**） |
| **白魔法 · 祝福系** | 祝福 | ❌ **帕特农专属觉醒**。普通觉醒中不可能出现 |
| **黑魔法** | 暗影、诅咒、亡灵、毒 | ⚠️ 极低概率（约 **1.8%**） |
| **次元魔法** | 召唤 | ⚠️ 极低概率（约 **0.1%**，有极少数初阶觉醒先例） |
| **次元魔法** | 空间、混沌、音系 | ❌ **高阶以下不可初阶觉醒**。音系需禁咒级别精神力 |

**初阶觉醒概率总表**

| 觉醒结果 | 概率 |
| --- | --- |
| 元素系（六系） | 约 96% |
| 雷系 | 约 0.1% |
| 白魔法（治愈/心灵/植物） | 约 2% |
| 黑魔法（暗影/诅咒/亡灵/毒） | 约 1.8% |
| 召唤系 | 约 0.1% |
| **合计** | **约 100%** |

### 4.2 各阶别突破时的觉醒规则

| 突破阶别 | 可觉醒系别 | 特殊事件 |
| --- | --- | --- |
| **中阶（第二系）** | 元素系（含雷）约 50%；白魔法约 20%；黑魔法约 20%；召唤约 8%；空间系约 2% | ❌ 无附效 |
| **高阶（第三系）** | 元素系（含雷）约 40%；白魔法约 20%；黑魔法约 20%；召唤约 10%；空间/混沌约 8%；音系约 2% | ⚠️ 约 **5%** 触发【系别异化】 |
| **超阶（第四系）** | 元素系（含雷）约 35%；白魔法约 15%；黑魔法约 15%；召唤约 10%；空间/混沌约 18%；音系约 5%；恶魔系约 2%（特殊） | ⚠️ 约 **15%** 触发【超阶附效】 |

### 4.3 超阶附效机制

#### 4.3.1 定义

高阶 / 超阶突破时，觉醒的新系有概率获得**超阶附效** —— 即该系自带另一个系的属性或特殊效果。

**对应原著**：莫凡超阶觉醒土系时，土系直接附带光系属性（金褐色岩土，自带圣光净化效果）。

#### 4.3.2 触发规则

| 阶别 | 触发概率 | 类型名称 |
| --- | --- | --- |
| 高阶突破 | 约 **5%** | 【系别异化】—— 附效效果较弱 |
| 超阶突破 | 约 **15%** | 【超阶附效】—— 附效效果完整 |

#### 4.3.3 附效类型池

| 附效名称 | 适用系别 | 效果描述 | 对应原著 |
| --- | --- | --- | --- |
| 光土融合 | 土系 | 土系附带光系净化效果，对黑暗系 / 亡灵系伤害 +30% | 莫凡超阶土系 |
| 焰土融合 | 土系 | 土系附带火系灼烧效果，命中后持续燃烧 | 莫凡岩鲨突袭变体 |
| 冰岩融合 | 土系 | 土系附带冰系减速效果，目标移速 -30% | 高阶以上技能可变 |
| 风土融合 | 土系 | 土系附带风系加速效果，施法速度 +20% | 同上 |
| 暗影寄生 | 暗影 / 诅咒系 | 黑魔法效果持续时间 +50% | 黑魔法高阶变异 |
| 圣光庇护 | 治愈 / 祝福系 | 被治疗目标获得短暂护盾 | 白魔法高阶变异 |
| 雷鸣共振 | 雷系 | 雷系命中后周围 3 米敌人受到 20% 溅射伤害 | 雷系高阶变异 |
| 混沌扭曲 | 混沌系 | 法术有概率使对方技能偏离目标 | 次元魔法高阶变异 |

#### 4.3.4 莫凡式觉醒（终极稀有事件）

**触发条件**：超阶突破时，极低概率（约 **3%**）触发。

**效果**：**同时觉醒两个系**（如土系 + 混沌系），且其中一个系附带超阶附效。

**对应原著**：莫凡超阶时觉醒土系（附带光系附效）+ 混沌系。

## 七、主要章节大纲

### 第一章：魔都 · 幸存者的觉醒

| 项目 | 内容 |
| --- | --- |
| **时间** | 圣城之战后第五年，秋季 |
| **地点** | 魔都 · 明珠学府预科部 / 某公立魔法高中 |
| **玩家状态** | 16 岁，博城遗孤，在魔都长大 |

**核心事件**：

## 八、附录：原著规则速查

| 规则项 | 说明 |
| --- | --- |
| 魔法释放流程 | 冥修 → 感知星尘 → 把控星子 → 连成星轨 / 星图 / 星座 / 星宫 → 释放 |
| 初阶魔法 | 星轨，7 颗星子 |
| 中阶魔法 | 星图，49 颗星子（7×7） |
| 高阶魔法 | 星座，343 颗星子（49×7） |
| 超阶魔法 | 星宫，2401 颗星子（343×7） |
| 新系修炼 | 新觉醒的系需从初阶一级开始修炼 |
| 高阶以上技能 | 可脱离固定形态，拥有更多变化 |
| 天生天赋 | 存在但稀有 |
| 罹灾者 | 极稀有，力量不受控制 |
| 精神力 | 把控星子消耗精神力，过度会精神崩溃 |
| 阶别突破 | 每突破一阶可觉醒新魔法系（中 / 高 / 超各一次） |
| 祝福系 | 仅帕特农神庙可觉醒 |
| 空间 / 混沌 / 音系 | 高阶以下不可初阶觉醒 |
| 音系 | 需禁咒级别精神力才可觉醒 |
