# 《仙途·问心》世界观设定

> 本文档整理自 `lib/gameData/lore.ts` 及各场景/人物/器物数据，是游戏世界观的完整设定总览。

---

## 一、时代背景：末道纪元

此方天地灵气不知自何时起日渐衰败。

- 上古修士举手可摘星辰，如今连筑基都已艰难。
- 修士们称此世为「**末道纪元**」——大道将绝，而众生仍在天光将熄处逆风执灯。
- 灵气衰败之下，妖兽修炼反比人快，妖兽之祸日益猖獗。

---

## 二、天地格局：九洲

- 此方天地广袤无垠，共分 **九块大洲**，以灵脉相连，故称「九洲」。
- 九洲之上，宗门林立，凡人仰仙，仙亦向天。
- 相传九洲之外更有**遗落之境**，只是无人得见。
- 当前游戏区域位于九洲中的**落星坡**一带。

---

## 三、修行体系

### 3.1 修行本质

修行，即是以己身契合天地灵气。六维根基：

| 概念 | 含义 |
|------|------|
| **道心** | 定内，决定修行心境与突破上限 |
| **灵蕴** | 养外，与灵气相合的底蕴 |
| **体魄** | 为基，决定气血与攻防基础 |
| **神识** | 为眼，探查四周、发现线索 |
| **因果** | 为绳，修行路上结下的业力（-100 ~ +100） |
| **执念** | 为障，心底未了的心事，心魔的种子（0 ~ 100） |

### 3.2 境界序列（十重）

凡胎 → 开脉 → 筑基 → 金丹 → 元婴 → 化神 → 合体 → 大乘 → 渡劫 → 飞升

- 凡躯引气入体为**开脉**，开脉凝液为**筑基**。
- 筑基乃修行第一道大关，凝液成海，心魔开始来犯。
- 金丹凝气成丹，夺天地造化，心魔必犯。
- 元婴金丹破碎，元婴初生，神游太虚，寿元大增。
- 化神元神与天地合一，一念动风云，需勘破生死。
- 合体元神与肉身彻底相融，因果渐重。
- 大乘道行圆满，抬手山河变色，天劫已在头顶酝酿。
- 渡劫九重天雷落下，渡得过便是仙，渡不过灰飞烟灭。
- 飞升仙门已开，举霞飞升，历经九劫九难终得正果。

### 3.3 天劫

修士夺天地造化，修行至深必引天妒。天劫降世，雷火交加：

- 渡得过则脱胎换骨；
- 渡不过则灰飞烟灭。
- 渡劫一境，是无数修士一生仰望又畏惧的终点——而再往上，便是飞升。

### 3.4 因果与执念

- **因果**：修行路上结下的业力。有善因便有善果，杀伐过重则因果缠身。
- **执念**：心底未了的心事，是心魔的种子。执念越深，境界越高时心魔越盛。
- **心魔**：突破高境界时的考验（筑基起触发）。多少天骄，皆陨于一个「放不下」。
- 游戏机制呼应：**执念 ≥ 70 时无法突破**，需先化解执念。

## 四、地域：落星坡

传说上古年间，一颗古星自天外坠落，轰然化作千里丘陵，故得名「落星坡」。

- 古星残存之力渗入地脉，使得此地灵气时浓时淡，妖兽格外躁动。
- 这里是散修与凡人的交界之地，也是当前所有剧情发生地。

### 各地场景

## 五、势力

### 青阳宗（正道大宗）
- 以剑修闻名的正道大宗，收徒极严，入宗需过护坛傀儡试炼。
- 分坛常年驻守落星坡，**明面除妖护民，暗中搜罗古星遗物**。
- 第一个发现并封锁落星坡秘境的组织。

### 散修盟
- 不是宗门，而是无门无派散修自发的松散同盟。
- 在溪风镇这等地方互相照应、交换情报。
- 没有宗门庇护的修士在此抱团取暖。

### 妖兽之祸
- 末道纪元灵气紊乱，妖兽修炼反比人快。
- 落星坡一带妖兽日益猖獗。
- 寻常妖兽尚可应付，若结巢穴、炼内丹，便是方圆千里大祸。

## 八、秘闻与主线暗线

### 残碑碑文
> 「……星陨于坡，神镇于此……百载血月，封印将溃……有缘人至，当继此责。」

### 山神陨落之谜
- 山神曾是落星坡守护者，以自身镇压古星遗祸。
- 百年前一夜之间，神像眉心开裂、庙中灵气尽散，山神陨落。
- 有老人说，那是末道纪元里又一位神明的谢幕。

### 落星坡血月
- 每逢血月当空，灵气紊乱到极点，妖兽成群躁动，古星残力隐隐回应。
- 残碑「百载血月，封印将溃」说的正是此时——真正的血月已近百年未现。

### 秘境入口
- 落星坡东北山崖裂口，古星陨落时遗下的秘境。
- 崖壁刻满古老禁制，灵气自裂隙如雾涌出。
- 传言深处藏有古星的核心遗物，**非金丹境不可入**。

### 剧情主线脉络
1. **残玉认主**：破庙醒来，须白老道指路。
2. **循玉简指引**：前往灵脉交汇之眼（白狐）。
3. **青木岭历练**：采药、猎妖、提升修为。
4. **溪风镇落脚**：打听消息、补给、接悬赏。
5. **筑就道基**：突破筑基 → 解锁断魂崖。
6. **斩妖除魔**：讨伐黑风妖（筑基·巅峰）。
7. **金丹入秘境**：突破金丹 → 解锁秘境入口（当前剧情终点）。

## 九、见闻录结构

游戏内以「见闻录」形式承载以上世界观，按 6 类收集解锁：

| 分类 | 内容 |
|------|------|
| 世界 | 九洲、末道纪元、灵气与修行、因果与执念、天劫 |
| 地域 | 落星坡各场景的来历与风貌 |
| 势力 | 青阳宗、散修盟、妖兽之祸 |
| 人物志 | 各主要人物的生平与秘辛 |
| 器物 | 关键道具的背景故事 |
| 秘闻 | 残碑、山神、血月、秘境等隐藏设定 |

**解锁机制**：首次进场景、与 NPC 对话、获得物品、完成任务等行为会触发对应见闻解锁，未解锁的条目只显示模糊线索提示（`unlockHint`）。
