## 核心主题

### 四道核心命题

1. **道心** — 何为道？每一次突破都是对内心的叩问。修行路上，最难的从来不是境界，而是面对自己。
2. **因果** — 所有选择皆有代价。善因善果，杀伐过重则因果缠身，每一步都算数。
3. **执念** — 放不下的人与事，是心魔之源，也是修行之根。执念越深，境界越高时心魔越盛。
4. **末道** — 灵气枯竭的时代，修士的挣扎与选择。大道将绝，而众生仍在天光将熄处逆风执灯。

### 叙事基调

- 古典仙侠叙事，融合东方哲学思辨
- 沉重但不绝望，黑暗中始终有光
- 每个选择都有意义，每个结局都是对道心的终极回答

## 世界观设定

### 九洲天地

此方天地广袤无垠，共分九块大洲，以灵脉相连，故称「九洲」。九洲之上，宗门林立，凡人仰仙，仙亦向天。相传在九洲之外更有遗落之境，只是无人得见。

### 末道纪元

天地灵气不知自何时起日渐衰败，上古修士举手可摘星辰，如今连凝液都已艰难。修士们称此世为「末道纪元」——大道将绝，而众生仍在天光将熄处逆风执灯。
