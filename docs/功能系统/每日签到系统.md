# 每日签到系统

> 模块：`stores/checkinStore.ts` · `components/modals/CheckinModal.tsx`
> 状态开关：`uiStore.checkinOpen`（`setCheckinOpen` / `closeCheckin`）
> 触发位置：`app/page.tsx`（玩家加载后，今日未签到自动弹出）

---

## 一、功能概述

每日签到系统为玩家提供**每日登录奖励**，采用**7 天一轮回的循环奖励体系**。玩家每天首次打开游戏时，若当日尚未签到，会自动弹出签到弹窗；签到后获得对应天数的奖励，并记录连续签到天数。

- **连续签到**：连续次日签到，进度累加（第 1→2→…→7 天）。
- **断签重置**：中间断签一天，连续天数重置为第 1 天。
- **循环轮转**：连续签到满 7 天后，从第 1 天重新开始循环。
- **当日防重复**：同一天内不会重复弹出或重复领取。

## 三、数据结构

### 3.1 奖励项 `CheckinReward`

```typescript
export interface CheckinReward {
  day: number;                                    // 天数（1~7）
  label: string;                                  // 奖励名称
  xiuwei: number;                                 // 修为
  lingShi: number;                                // 灵石
  daoxin: number;                                 // 道心
  lingyun: number;                                // 灵蕴
  tipo: number;                                   // 体魄
  items: { itemId: string; count: number }[];     // 物品（引用 items.ts 中的 id）
}
```

### 3.2 签到状态 `CheckinState`

```typescript
interface CheckinState {
  lastCheckinDate: string | null;   // 上次签到日期（YYYY-MM-DD）
  consecutiveDays: number;          // 连续签到天数
  hasCheckedInToday: () => boolean; // 今日是否已签到
  getTodayReward: () => CheckinReward; // 获取今日应得的奖励项
  checkin: () => CheckinReward | null; // 执行签到，成功返回奖励，失败（已签）返回 null
}
```

## 四、签到逻辑

### 4.1 日期判断

- **今日**：`new Date()` 格式化为 `YYYY-MM-DD`。
- **昨日**：今日日期减 1 天。

### 4.2 连续签到判定

```typescript
if (lastCheckinDate === today) {
  return null; // 今日已签到，拒绝重复领取
}

let newStreak: number;
if (lastCheckinDate === yesterday) {
  newStreak = consecutiveDays + 1; // 连续签到
} else {
  newStreak = 1; // 断签或首次签到
}

if (newStreak > 7) newStreak = 1; // 7 天循环

const reward = CHECKIN_REWARDS[newStreak - 1];
```

### 4.3 奖励发放

签到成功后，`CheckinModal.handleCheckin()` 依次调用：

| 奖励类型 | 调用方法 |
| ------- | ------- |
| 修为 | `playerStore.gainXiuwei()` |
| 灵石 | `playerStore.gainLingShi()` |
| 道心 | `playerStore.updateStats()`（受上限钳制） |
| 灵蕴 | `playerStore.updateStats()`（受上限钳制） |
| 体魄 | `playerStore.updateStats()` |
| 物品 | `playerStore.addItem()`（逐件加入） |

奖励发放后写入日志，并自动关闭签到弹窗。

## 五、UI 说明

### 5.1 签到弹窗 `CheckinModal`

- 顶部标题栏 + 关闭按钮（点击可跳过今日签到）。
- 中央显示当前连续签到天数（`X / 7`）。
- 下方列表展示 7 天全部奖励：
  - **今日奖励**：金色高亮 + 「👈 今日」标记，可点击领取。
  - **已领奖励**：灰暗 + 「✓」标记。
  - **未领奖励**：半透明显示。
- 底部签到按钮：未签时显示「✦ 领取今日奖励」，已签时禁用并显示「今日已签到」。

### 5.2 触发时机

在 `app/page.tsx` 的 `useEffect` 中：

```typescript
if (player && !hasCheckedInToday()) {
  setCheckinOpen(true); // 玩家已加载且今日未签到时自动弹出
}
```

> 无论当天是否已签到，弹窗仍可通过关闭按钮关闭；已签到的玩家不会再次弹出。

## 六、持久化

- 存储 key：`checkin-storage`（localStorage）。
- 字段：`lastCheckinDate`、`consecutiveDays`。
- 通过 zustand `persist` + `merge` 向后兼容，缺失字段回退默认值（`null` / `0`）。

## 七、扩展指南

| 想改什么 | 改哪里 |
|---------|--------|
| 调整奖励数值 | `stores/checkinStore.ts` 的 `CHECKIN_REWARDS` |

| 新增奖励类型 | 在 `CheckinReward` 加字段，并在 `CheckinModal.handleCheckin()` 加入发放逻辑 |

| 修改签到周期 | 修改天数上限与 `CHECKIN_REWARDS` 长度 |
