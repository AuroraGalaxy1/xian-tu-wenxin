# 《仙途·问心》功能框架总览

> 本文档整理自 `types/`、`stores/`、`lib/gameData/`、`lib/utils/`、`components/`，说明游戏各功能模块的能力与实现框架。

---

## 一、技术架构

- **框架**：Next.js 16（App Router）+ React 19 + TypeScript
- **状态管理**：Zustand 5（全局 store，多模块持久化）
- **样式**：Tailwind CSS 4 + framer-motion（动效）
- **图标**：lucide-react
- **运行方式**：纯前端单机文字游戏，无后端；存档存 localStorage

### 目录结构

```
lib/gameData/   游戏数据（世界观/场景/NPC/物品/任务/敌人/奇遇/成就/境界）
types/          各系统 TypeScript 类型定义
stores/         Zustand 状态管理（玩家/战斗/背包/地图/UI/见闻/成就/日志/场景）
lib/utils/      数值规则纯函数（修炼/突破/战斗/掉落/遭遇）
lib/hooks/      业务 Hooks（预留）
components/     UI（layout 四宫格布局 + game 游戏组件 + modals 弹窗 + ui 基础件）
app/game/       游戏主页面
```

## 二、各功能模块

### 1. 境界修炼系统

**数据**：[realms.ts](lib/gameData/realms.ts) · [realm.ts](types/realm.ts)

- 十二重内景次第境界序列：感气→通脉→凝液→玉府→婴胎→神游→炼神→开界→合道→历劫→忘机→超脱。
- 每境界定义：累计修为需求、道心上限、灵蕴上限、突破条件（道心+灵蕴）、突破描述、是否触发心魔。
- **双属性突破**：突破需同时满足「修为 ≥ 需求 + 道心 ≥ 门槛 + 灵蕴 ≥ 门槛」。
- **心魔机制**：凝液起 `hasMindDemon: true`；执念 ≥ 70 时锁定突破。
- 突破成功后：切换境界、扣除修为、提升属性上限与战斗面板、解锁新地图区域（凝液→断魂崖、玉府→秘境）。
- 修炼收益：打坐获得修为（受灵气浓度与境界影响），修炼获得道心/灵蕴（境界越高越难）。

### 2. 场景系统

**数据**：[scenes.ts](lib/gameData/scenes.ts) · [scene.ts](types/scene.ts)

- 10 个场景，每个含：名称/描述、地图坐标、灵气浓度、危险度、游戏时辰、动作列表、出口、NPC 列表、可拾取物品。
- **动作驱动**：每个动作有 `type`（explore/meditate/combat/talk/shop/rest/gather/backpack/leave/info…）与 `payload`（npcId/enemyId/itemId），由 [CenterPanel.tsx](components/layout/CenterPanel.tsx) 统一 switch 分发。
- 场景出口含锁定标记；首次进入触发任务自动接取与地域见闻解锁。

### 3. 战斗系统

**状态机**：[combatStore.ts](stores/combatStore.ts) · [enemy.ts](types/enemy.ts)

- 回合制指令战斗，阶段机：idle → player_turn → enemy_turn → victory/defeat/fled。
- 玩家指令：**攻击 / 重击（2 回合冷却）/ 防御（减伤）/ 使用丹药（仅恢复类）/ 逃跑（60% 成功率）**。
- 敌人：技能表（每技能有伤害系数）+ 掉落表（逐条概率掷骰）+ 击杀修为。
- 结算：胜利获得修为与掉落并记录击杀；战败自动送回最近城镇（溪风镇/破庙）并回血 1 点。
- 玩家战斗面板由「境界 + 体魄 + 装备加成」派生（`getPlayerCombatStats`）。

### 4. 任务系统

**数据**：[quests.ts](lib/gameData/quests.ts) · [quest.ts](types/quest.ts)

- 主线 q1~q5 + 支线 s1~s7，状态机：locked → pending → active → completed。
- 5 种目标类型：`scene_visit`（到达场景）/ `realm`（突破境界）/ `kill_enemy`（击杀）/ `collect_item`（收集）/ `xiuwei`（修为达标）。
- **自动接取**：首次进入目标场景自动接主线/场景类支线；突破筑基且完成 q4 后自动接讨伐黑风妖主线 q5。
- **自动结算**：`evaluateQuests()` 统一判定，达成即发奖（修为/灵石/物品），并触发世界/势力见闻解锁。

### 5. 物品 / 背包系统

**数据**：[items.ts](lib/gameData/items.ts) · [item.ts](types/item.ts)

- 5 大类：丹药、材料、法宝、功法、杂物。
- 5 级稀有度：凡品→灵品→玄品→宝品→仙品（各带显示色）。
- 丹药/功法带使用效果（恢复气血、加修为/道心/灵蕴/体魄等）；法宝带装备槽（武器/护甲/饰品）与攻防加成。
- 物品可堆叠、可购买（NPC 商店）、掉落概率配置；背包弹窗支持使用/装备/查看详情。

### 6. NPC / 对话 / 商店系统

**数据**：[npcs.ts](lib/gameData/npcs.ts) · [npc.ts](types/npc.ts)

- NPC 含：称号、境界、所在场景、对话轮次（轮流展示）、商店出售列表、可绑定任务。
- 场景动作 `talk`/`shop` 携带 npcId，由 UI 弹窗承载对话与购买。
- 对话会解锁人物/地域见闻；好感度字段已预留（`player.relationships`）。

### 7. 见闻录（Lore）系统

**数据**：[lore.ts](lib/gameData/lore.ts) · [lore.ts](types/lore.ts)

- 6 类见闻：世界/地域/势力/人物志/器物/秘闻。
- 每条见闻：正文 + 未解锁线索提示；支持按分类筛选展示。
- **多途径解锁**：首次进场景（`sceneLoreMap`）、与 NPC 对话（`npcLoreMap`）、获得物品（`itemLoreMap`）、完成任务、探查随机窥见秘闻（35% 概率）。
- 解锁状态持久化，见闻录弹窗按分类浏览。

### 8. 奇遇系统

**数据**：[encounters.ts](lib/gameData/encounters.ts) · [encounter.ts](types/encounter.ts)

- 8 个随机事件：高人传功、路拾遗物、灵狐引路、横遭劫修、血月异象、采药偶得、灵玉原石、前辈赠丹。
- 结果类型：修为/道心/灵蕴/物品/灵石/回血/解锁地点/触发战斗。
- 触发方式：探查四周时 25% 概率随机触发，以弹窗呈现。

### 9. 成就系统

**状态机**：[achievementStore.ts](stores/achievementStore.ts) · [achievement.ts](types/achievement.ts)

- 10 种判定类型：突破、击杀指定敌人、击败 N 种敌人、获得物品、到访场景、到访全部地点、修为/灵石达标、完成任务、背包物品种类数。
- **自动评估**：订阅 playerStore 状态变化，达成即原子解锁、自动发放奖励、写入日志。
- 现有 12 项成就，覆盖新手引导到主线通关的成长节点。

### 10. 地图 / 罗盘导航系统

**状态机**：[mapStore.ts](stores/mapStore.ts) · [map.ts](types/map.ts)

- 10 个地点：坐标 + 区域 + 类型（场景/城镇/危险/资源/秘地）+ 解锁/探索状态。
- 地点通过突破境界、首次到达等解锁；罗盘（CompassMap）选择目的地。
- `merge` 合并旧存档，保证新增地点对老玩家生效。

### 11. UI 框架

- **四宫格布局**：
  - TopBar：Logo、境界、顶部功能入口
  - LeftPanel：功能导航（修炼/战斗/背包/见闻/地图/社交/洞府/奇遇/更多）
  - CenterPanel：玩家状态条 + 场景描述 + 动作按钮 + 罗盘
  - RightPanel：日志 + 任务面板 + 玩家列表
  - BottomBar：在线人数/延迟等氛围展示
- **弹窗系统**（`uiStore` 统一控制开关）：修炼、背包、战斗、奇遇、商店、NPC 对话、物品详情、见闻录、成就，共 9 个弹窗。
- 古风视觉：深色底 + 金色描边 + 玻璃拟态面板。

### 12. 存档系统

- 各 store 使用 Zustand `persist` 持久化到 localStorage（key：`player-storage` / `map-storage` / `achievement-storage` 等）。
- **向后兼容**：`merge` 函数用最新数据定义合并旧存档，缺失字段回退默认值，新增内容不破坏旧档。

## 三、扩展新内容指南

这套框架是**数据驱动**的，新增内容大多只需加数据、无需改逻辑：

| 想加什么 | 改动位置 |
|----------|----------|
| 新场景 | `lib/gameData/scenes.ts` + `lib/gameData/lore.ts`(地域见闻) + `stores/mapStore.ts`(地图点) |
| 新 NPC | `lib/gameData/npcs.ts` + 场景 `npcs` 字段 + `lore.ts` 人物见闻 |
| 新敌人 | `lib/gameData/enemies.ts` + 场景 combat 动作 payload |
| 新物品 | `lib/gameData/items.ts` + NPC 商店或掉落表引用 |
| 新任务 | `lib/gameData/quests.ts`（若需对话接取，在 NPC 加 `questId`） |
| 新成就 | `lib/gameData/achievements.ts` |
| 新奇遇 | `lib/gameData/encounters.ts` |
| 新见闻 | `lib/gameData/lore.ts` + 对应解锁映射 |

> 注意：本项目使用非标准 Next.js 版本，改动前请先阅读 `node_modules/next/dist/docs/` 中的相关指南（见 [AGENTS.md](AGENTS.md)）。
