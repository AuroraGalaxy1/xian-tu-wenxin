### 核心系统依赖

在开始 Phase 2 之前，需要确保以下系统已就绪：

1. **任务系统**：`playerStore` 中的任务进度评估逻辑需要支持新 Objective 类型（dialog / choice / survive / collect_all / reputation / lore）
2. **场景解锁系统**：`scenes.ts` 中的 `isUnlocked` 条件需要支持境界判断和前置任务判断
3. **对话链系统**：NPC 对话需要支持条件分支（基于属性/任务进度/已解锁见闻）
4. **突破系统**：玉府→婴胎→神游→炼神→开界→历劫 的突破逻辑

### 2.1 新增场景（scenes.ts）

#### 秘境区域（3个）

| ID | 名称 | 类型 | 解锁条件 | 入口 | 出口 |
|----|------|------|---------|------|------|
| `mi_jing_1` | 星陨秘境·外围 | 危险 | 玉府突破 | mi_jing_ru_kou | mi_jing_2 |
| `mi_jing_2` | 星陨秘境·核心 | 极危 | 探索外围后 | mi_jing_1 | mi_jing_3 |
| `mi_jing_3` | 星核大厅 | 秘地 | 探索核心后 | mi_jing_2 | 无（剧情传送） |

**秘境设计要点**：
- 秘境外围有扭曲灵气效果，视觉上用幽蓝/紫色调
- 核心区域有古星记忆碎片交互点（每次交互解锁一段记忆回放）
- 星核大厅中央悬浮星核残骸，周围有星灵守护

#### 九洲·东域（4个）

| ID | 名称 | 类型 | 解锁条件 | 入口 | 出口 |
|----|------|------|---------|------|------|
| `luo_xia_cheng` | 落霞城 | 城镇 | 离开秘境后 | mi_jing_3 | qing_yang_zong, qian_ji_feng, cang_wu_gu |
| `qing_yang_zong` | 青阳宗山门 | 势力 | 落霞城剧情 | luo_xia_cheng | 落霞城 |
| `qian_ji_feng` | 千机峰 | 场景 | 离开秘境后 | luo_xia_cheng | 落霞城 |
| `cang_wu_gu` | 苍梧谷 | 资源 | 通过落霞城 | luo_xia_cheng | 落霞城 |

**场景坐标规划**（落星坡区域坐标约 0-4, 0-4）：
- 落霞城作为新区域起点，建议坐标从 5,0 开始
- 或者使用独立的地图区域 ID

### 2.8 剧情对话链设计

#### 星灵对话链（q9）

```
阶段1（初次见面）：
  星灵："万年了……终于有人走到这里。"
  星灵："你身上有山神的气息……不，是残玉。你是山神选中的继承者？"
  选项A："山神已经陨落了。" → 继续
  选项B："残玉指引我来的。" → 继续
  选项C："什么是山神？" → 星灵解释山神来历

阶段2（古星真相）：
  星灵："这颗古星，名为'问道星'。"
  星灵："它不是天外陨石，而是上古大能炼制的天外之器。"
  星灵："它的核心封印着一个可怕的存在——毁灭意志。"
  选项A："毁灭意志是什么？" → 星灵解释
  选项B："为什么要封印它？" → 星灵解释
  选项C："封印……现在怎么样了？" → 关键剧情

阶段3（封印现状）：
  星灵："百年前，有人闯入秘境，破坏了封印，偷走了星核碎片。"
  星灵："山神为了阻止毁灭意志脱困，以自身神格加固封印……"
  星灵："也因此陨落。"
  星灵："你身上的残玉，就是山神破碎的神格核心。"
```

## 类型扩展计划

### 扩展 QuestObjective 类型

```typescript
// 当前类型（types/quest.ts）
export type QuestObjectiveType = 'scene_visit' | 'realm' | 'kill_enemy' | 'collect_item' | 'xiuwei';

// 扩展后
export type QuestObjectiveType = 'scene_visit' | 'realm' | 'kill_enemy' | 'collect_item' | 'xiuwei'
  | 'dialog'          // 与指定NPC对话
  | 'choice'          // 做出特定选择
  | 'survive'         // 在战斗中存活指定回合数
  | 'collect_all'     // 收集全套物品
  | 'reputation'      // 达到某势力好感度
  | 'lore'            // 解锁特定见闻
  | 'breakthrough'    // 突破到指定境界
  | 'defeat_boss'     // 击败特定BOSS（含阶段要求）
  | 'attribute'       // 属性达到指定值
  | 'event'           // 触发特定事件
  | 'ally'            // 招募/保护盟友
  | 'survive_waves';  // 抵御多波敌人
```

```typescript
// 为BOSS战添加阶段支持

  }>;

// 可选扩展字段
export interface Enemy {
  // ... 现有字段
```
