## 概述

- **境界跨度**：感气 → 玉府
- **核心内容**：残玉认主、初入修行、断魂崖斩妖、玉府入秘境
- **主线任务**：q1「残玉指引」→ q2「灵脉初探」→ q3「溪风镇」→ q4「凝液化府」→ q5「斩妖除魔」
- **目标规模**：10 场景 / 9 NPC / 9 敌人 / 25 物品 / q1–q5 主线 + s1–s7 支线 / 29+ 见闻 / 12 成就

### 规划目标

1. 打通 **感气 → 通脉 → 凝液 → 玉府** 完整修行闭环；
2. 主线 q1–q5 可全程自动接取、自动结算，直至斩杀黑风妖；
3. 补齐第一幕全部场景 / NPC / 敌人 / 物品 / 支线，兑现《剧情大纲》第一幕承诺；
4. 恢复并接线**见闻录 / 奇遇 / 心性抉择**三个弹窗系统（当前为未接线的 WIP）；
5. 修复因历史合并冲突导致的**编译错误**，恢复 `npm run build` 通过；
6. 为 Phase 2（秘境与青阳宗）铺好核心系统依赖。
